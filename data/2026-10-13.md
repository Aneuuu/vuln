# 运维安全漏洞简报（2026-10-13 北京时间）
本日只核对了少量来源，部分数据来自第三方文章，内容可能不全。
## 高危
- **CVE-2026-46116** Linux 内核 xfrm（IPsec）释放后使用，本地提权，CVSS 7.8。修复：上游 5.15.210 / 6.1.176 / 6.6.140 / 6.12.88 / 6.18.30 / 7.0.7；Ubuntu 24.04 ≥ 6.8.0-136.136，26.04 ≥ 7.0.0-28.28。缓解：`kernel.unprivileged_userns_clone=0`。来源（第三方）：[rodhat.com](https://rodhat.com/motd/2026-10-13-cve-2026-46116-xfrm-ipsec-uaf/)
- **RHEL 系内核合集更新** AlmaLinux ALSA-2026:76738（Important），修复数十个内核 CVE（netfilter、ipvs、IPv6、KVM、RDMA、蓝牙）。`dnf update kernel` 后重启。[AlmaLinux 公告](https://lists.almalinux.org/archives/list/announce@lists.almalinux.org/thread/FVG5663UV2RFJHZ7EFEYHTF7BFE4S3F4/?sort=date)
- **CVE-2026-83923** 仅影响微软 OpenSSH for Windows，路径穿越致未认证 RCE；Linux OpenSSH 不受影响。打对应 Windows KB。[AcidPeak](https://www.acidpeak.com/threats/cve-2026-83923/) · [MSRC](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-83923)
## 中危：Grafana
- CVE-2026-15577 / 33374 / 93294 / 95502，CVSS 5.3–6.5，涉及 Git Sync 权限与内存耗尽、Prometheus 规则转换 API、Azure Monitor 数据源代理。[Grafana 安全公告](https://grafana.com/security/security-advisories/)
## Kubernetes / containerd
- containerd 检查点恢复漏洞（需节点装 `criu`），升级到 2.3.4+ / 2.2.7+，保持 `enable_experimental_restore_via_create=false`。CVE 编号未确认。[GKE 安全公告](https://docs.cloud.google.com/kubernetes-engine/security-bulletins)
## 范围外：已在野利用
- CISA KEV 新增 Ivanti Connect Secure（CVE-2026-104935）与 Windows Shell（CVE-2026-96951）。[CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)
