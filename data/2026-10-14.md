# 运维安全漏洞简报（2026-10-14）
重点是 Nginx 一批内存安全漏洞，以及 Ubuntu 侧 OpenSSH / Apache / Bind / curl 更新。均未见在野利用报告。
## 高危：Nginx（CVSS 3.1 8.1）
- **CVE-2026-97205** SSI + AIO 场景释放后使用，可致 worker 崩溃，极端条件下可能代码执行。
- **CVE-2026-93479** `map` + 正则捕获堆溢出，影响 1.31.2–1.31.6、1.30.0–1.30.5。
- **CVE-2026-15176** `alias` + `rewrite` + `$request_filename` 组合堆溢出。
- 另有中危 CVE-2026-95101（HTTP/3 请求体注入）、CVE-2026-97629（TLS session ticket 伪造）。
- 修复：开源版 **1.30.6 / 1.31.7**，Plus 37.0.5.1 / 37.1.0.1。临时关 AIO 或 SSI。[nginx 安全公告](http://nginx.org/en/security_advisories.html)
## 运维常见组件
- **OpenSSH** [USN-8928-1](https://ubuntu.com/security/notices/USN-8928-1)：9 个 CVE（sftp 路径穿越 CVE-2026-106552、GSSAPI 状态残留等），上游 < 10.6 受影响。24.04 `1:9.6p1-3ubuntu13.20`，22.04 `1:8.9p1-3ubuntu0.18`。
- **Apache** [USN-8931-1](https://ubuntu.com/security/notices/USN-8931-1)：CVE-2026-63292（DoS / 任意代码执行）、响应走私、Digest 认证绕过。24.04 `2.4.58-1ubuntu8.17`。
- **Bind9** [USN-8929-1](https://ubuntu.com/security/notices/USN-8929-1)：大批 DoS / DNSSEC 绕过 / 缓存投毒。24.04 `1:9.18.39-0ubuntu0.24.04.8`。
- **curl/libcurl** [USN-8932-1](https://ubuntu.com/security/notices/USN-8932-1)：[CVE-2026-92388](https://curl.se/docs/CVE-2026-92388.html)（FTP 通配符 UAF，低危）及凭证泄露、HSTS 问题。
## 其他
- 无新公告：Kubernetes 核心组件、Linux 内核主流版本。
