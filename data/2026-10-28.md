# 运维安全漏洞简报（2026-10-28）
头号事项：CISA 10-28 把 Linux 内核 CVE-2026-46300 加入 KEV，确认在野利用，且可与 PHP「PHP2Shell」CVE-2026-109618/109619 串联植入 Webshell 并以 root 执行命令，修复截止 10-31（只有 3 天），所有 Linux 主机请尽快升内核。Java 方面 jackson-databind 又出 9.8 反序列化绕过（CVE-2026-54512 的修复不完整），Node.js 方面 undici 一次发了 4 个高危。另有 WatchGuard Fireware OS、Dell PowerProtect Data Domain 两批严重漏洞。全量扫 NVD 窗口约 804 条，CVSS ≥9 大部分是 WordPress 插件、Adobe Campaign、Chrome 等，本报只收运维/OS/云与网络设备相关项。
## 已被在野利用
- **[CVE-2026-46300 Linux 内核 skbuff 共享分片标记丢失](https://nvd.nist.gov/vuln/detail/CVE-2026-46300)**：`skb_try_coalesce()` 合并时丢掉 shared-frag 标记，ESP（IPsec）入站处理会原地解密共享分片，进而篡改页缓存里的文件数据，CVSS 7.8。10-28 进 [CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)，截止 10-31，要求做取证排查；CISA 称可与 PHP [CVE-2026-109618](https://nvd.nist.gov/vuln/detail/CVE-2026-109618)（9.8）/ [CVE-2026-109619](https://nvd.nist.gov/vuln/detail/CVE-2026-109619) 串联植入 PHP Webshell 并以 root 执行命令。修复已进各 stable 分支（[补丁提交](https://git.kernel.org/stable/c/3599e6b3cc1ada96883d496a50a210d3afbb6987)），按发行版内核更新升级并重启；跑 PHP 的机器同时确认 PHP 已升到 10-21 的修复版，并排查 Webshell。
- **[CVE-2026-41709 VMware ESX 日志记录不足](https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/38017)**：管理员权限的攻击者可执行操作而不留日志，CVSS 2.7（7 月公布，10-28 新进 KEV，截止 11-11）。分值低但已被利用，用于攻击后隐藏痕迹，按 Broadcom 公告打补丁。
## 严重
- **[WatchGuard Fireware OS 一批](https://psirt.watchguard.com/CVE-2026-93857)**：SIP 代理栈溢出未授权 RCE [CVE-2026-93857](https://nvd.nist.gov/vuln/detail/CVE-2026-93857)（9.2）、Access Portal WebSocket 整数溢出 CVE-2026-93866（9.2）、FireCluster 同步缺认证 CVE-2026-93865（9.2）/ CVE-2026-90465（9.4）、WireGuard 配置栈溢出 CVE-2026-103594（9.5）、认证服务堆溢出 CVE-2026-112709/112710（9.2）、SSH 认证 XPath 注入 CVE-2026-93434（8.7）等。升级 Firebox 固件到公告修复版本；未用 SIP 代理的策略可先关闭，管理口与集群互联口不要暴露。
- **[Dell PowerProtect Data Domain DSA-2026-416](https://www.dell.com/support/kbdoc/en-us/000515178/dsa-2026-416-security-update-for-dell-powerprotect-data-domain-multiple-vulnerabilities)**：[CVE-2026-86397](https://nvd.nist.gov/vuln/detail/CVE-2026-86397) 未认证远程创建特权账户，可完全接管（9.8），同批 CVE-2026-86400、86384、103780（9.8）及 Management Center 多条 9.1–9.6。影响 7.7.1.0–8.8 及 LTS2024/2025/2026 各线，Dell 要求尽快升级。
- **[Eclipse Che che-machine-exec CVE-2026-114278](https://nvd.nist.gov/vuln/detail/CVE-2026-114278)**（K8s 云 IDE 组件）：`/exec/init`、`/exec/config` 的 username/namespace 直接拼进 `sh -c`，默认无认证，可在其能访问的容器里 RCE，CVSS 9.8。按 [修复提交](https://github.com/eclipse-che/che-machine-exec/commit/a78541c29e5f48fd59a49cf206bc0e507628bd23) 升级，并限制该服务的网络可达性。
- **jackson-databind CVE-2026-110879**（Java，9.8）：见下方「Java 生态」。
## 高危
- **[X.Org X Server / XWayland 一批](https://nvd.nist.gov/vuln/detail/CVE-2026-93517)**：GLX、XKB、XFIXES 多处堆溢出与 double free（CVE-2026-93517 8.5、93518/93519/93520、88812 7.8），已连接的 X 客户端可提权或打崩服务。升到 X server `21.1.25` / XWayland `24.1.14`，或等发行版包；另 libXi `< 1.8.4` 两个堆溢出（CVE-2026-109089/109090，7.5）。
- **[libexpat CVE-2026-117610](https://nvd.nist.gov/vuln/detail/CVE-2026-117610)**（系统库）：外部实体子解析器空输入导致空指针，可打崩应用，CVSS 4.0 8.2（3.1 为 5.9）；同批 CVE-2026-118370 `storeAtts()` 整数溢出（8.2）。影响 `<= 2.9.0`，修复见 [PR #1444](https://github.com/libexpat/libexpat/pull/1444)，等发行版更新。
- **[Veeam 一批](https://nvd.nist.gov/vuln/detail/CVE-2026-106076)**：Backup & Replication 组织迁移 SQL 注入 CVE-2026-106076（9.0）、CDP Coordinator 未认证授权绕过 CVE-2026-108142（9.1）、Veeam Agent for Linux 本地提权 CVE-2026-105477（7.3）等，按 Veeam 公告升级。
- **[TeamViewer 一批](https://nvd.nist.gov/vuln/detail/CVE-2026-92372)**：Linux/macOS 客户端屏幕解码越界写 CVE-2026-92372（8.8）、Windows 远控整数溢出 CVE-2026-111585（8.8）、多处本地提权（7.3–7.8）。Full Client/Host 升到 `15.83`。
- **[MLflow CVE-2026-116692](https://github.com/mlflow/mlflow/security/advisories/GHSA-26p8-2jq9-3vq9)**：第三方 scorer 反序列化可加载上传模块，关认证时无需凭据即可 RCE，CVSS 9.8。3.12.0rc0–&lt;3.17.0 → `3.17.0`。
- **[Authlib CVE-2026-116672](https://nvd.nist.gov/vuln/detail/CVE-2026-116672)**（Python）：ClientConfigurationEndpoint 授权缺陷，CVSS 8.8。0.15–&lt;1.9.1 → `1.9.1`（昨天报过的 Authlib 1.9.0 之后又一条）。
- **[Atlantis CVE-2026-116676](https://nvd.nist.gov/vuln/detail/CVE-2026-116676)**（Terraform PR 自动化，Go）：CVSS 8.8，0.4.0–&lt;0.47.1 → `0.47.1`。
## Java 生态
- **[jackson-databind CVE-2026-110879](https://github.com/FasterXML/jackson-databind/security/advisories/GHSA-m8xf-2cr7-77ph)**（GHSA Critical，CVSS 9.8）：PolymorphicTypeValidator 只校验外层类，泛型参数和数组元素里可塞任意类，绕过 CVE-2026-54512 的修复，开启多态类型（Default Typing / `@JsonTypeInfo` 类名）时可任意类实例化进而 RCE。升到 `2.18.12` / `2.21.8` / `2.22.4`，Jackson 3 升到 `3.1.8` / `3.2.4`。Spring Boot 等项目请检查传递依赖版本。
- **[jackson-dataformat-protobuf CVE-2026-104016](https://github.com/FasterXML/jackson-dataformats-binary/security/advisories/GHSA-c2rq-mcfv-jw29)**：长度字段整数溢出导致超大数组分配，OOM DoS，`-Xmx` 无法缓解，CVSS 7.5；同类 CVE-2026-110747。修复版本同上（`2.18.12` / `2.21.8` / `2.22.4` / `3.1.8` / `3.2.4`）。
- **[jackson-dataformat-smile CVE-2026-104895](https://github.com/FasterXML/jackson-dataformats-binary/security/advisories/GHSA-h3c2-2m49-r49w)**：异步 Smile 解析器约 10 字节即可触发约 2 GB 分配，OOM DoS，CVSS 7.5。修复版本同上。
- **[Debian OpenJDK 更新](https://www.debian.org/security/2026/dsa-6591)**：DSA-6591-1 openjdk-25、[DSA-6588-1 openjdk-21](https://www.debian.org/security/2026/dsa-6588)，对应 Oracle 10 月 CPU 的 OpenJDK 修复，Debian 主机请升级 JDK 包。
