# 运维安全漏洞简报（2026-11-01）
头号事项：开源 Serverless/GPU 容器平台 [Beta9 三连严重漏洞](https://github.com/beam-cloud/beta9/releases/tag/worker-0.1.756)（CVE-2026-120306/120307/120308，CVSS 均 9.9）— 持有 workspace token 的租户可逃出构建/沙箱，以 root 读写 worker 宿主文件、拿到绑定 cluster-admin 的 K8s ServiceAccount token，跨租户越权；请升 worker `0.1.756`、gateway `0.1.776`。另外 [Gitea 28.3.0](https://blog.gitea.com/release-of-28.3.0/) 一次修了约 20 个 CVE（含 PR review 触发的 Actions 工作流可无审批拿仓库 secrets、OAuth2 自动关联账号免密登录），自建 Gitea 建议尽快升级；Java 侧 [Apache MINA 3.0 反序列化 RCE](https://lists.apache.org/thread.html/h76nwcrkvsffhsk2kq6cjzc6srtnty7x)（9.8，分支已停维不修）与国产运维平台 [Jpom 认证绕过](https://www.vulncheck.com/advisories/jpom-2.10.0-through-2.11.12-authentication-bypass-via-jpom-user-token-header)（9.8，可直达脚本执行）需排查。CISA KEV 当日无新增；Ivanti Connect Secure CVE-2026-111357 修复截止就是今天（11-02）。NVD 本窗口新发布 78 条、CRITICAL 18 条（以 WAVLINK / D-Link / 蒲公英路由器命令注入为主），GHSA Maven / npm 生态无新增 High/Critical。
## 已被在野利用
- 无新增：CISA KEV 目录版本仍为 `2026.10.30`，`dateAdded=2026-11-01` 为 0。提醒：10-30 入库的 [CVE-2026-111357 Ivanti Connect Secure 缺失认证](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) 联邦修复截止为 **11-02（今天）**，需按 CISA 要求做取证与补丁；同链路 CVE-2026-118527 截止 11-13，详见 10-30 简报。
## 严重
- **[Beta9 CVE-2026-120306 / 120307 / 120308](https://github.com/beam-cloud/beta9/pull/1897)**（K8s 上的容器/Serverless 平台）：① 镜像构建 Buildah 用 `chroot` 隔离，RUN 步骤共享 worker 的 PID/网络/IPC 命名空间并以 uid 0 + `CAP_DAC_OVERRIDE` 运行，可经 `/proc/1/root` 改写特权 worker 的 runc/buildah 与 SA token（[GHSA-xvhg-75x6-gj86](https://github.com/advisories/GHSA-xvhg-75x6-gj86)）；② 沙箱文件 API 路径拼接可用 `..`/符号链接逃逸，以 root 读写 worker 文件，PoC 读到绑定 cluster-admin 的 SA token（[GHSA-6h4h-qffc-3gfp](https://github.com/advisories/GHSA-6h4h-qffc-3gfp)）；③ 挂卷时 volume 标识未校验归属，可把 worker 根目录读写挂进沙箱（[GHSA-92w2-g272-fr77](https://github.com/advisories/GHSA-92w2-g272-fr77)）。均 CVSS 9.9，需低权限租户 token，未见在野利用。修复：worker `0.1.756`、gateway `0.1.776`（[release](https://github.com/beam-cloud/beta9/releases/tag/gateway-0.1.776)）。
- **[Apache MINA 3.0 CVE-2026-118636](https://lists.apache.org/thread.html/h76nwcrkvsffhsk2kq6cjzc6srtnty7x)**（Java 网络框架）：3.0 codec 模块 `JavaNativeMessageDecoder` 对帧数据直接 `ObjectInputStream.readObject()` 且无类过滤，面向不可信对端时可 gadget 链 RCE。CVSS 9.8，标注 UNSUPPORTED WHEN ASSIGNED：3.0 分支已停止维护、**不会出修复版**，官方建议改用 MINA `2.2.x` 最新版（见 [oss-security](http://www.openwall.com/lists/oss-security/2026/10/31/3)）。
- **[Jpom CVE-2026-120201](https://nvd.nist.gov/vuln/detail/CVE-2026-120201)**（Java 运维/部署平台）：`JPOM-USER-TOKEN` 头传入如 `is not null` 会被 Hutool Condition 解析器当成操作符，未认证即可拿超级管理员，再经脚本功能执行命令。CVSS 9.8，未见在野利用报告。影响 `2.10.0`–`2.11.12`，NVD 未给修复版本，跟踪 [上游 issue #121](https://github.com/dromara/Jpom/issues/121)；临时勿将 Jpom 暴露公网、加前置认证/IP 白名单。
- **[AJ-Report CVE-2026-120209](https://www.vulncheck.com/advisories/aj-report-through-1.7.1-authentication-bypass-leading-to-rce-via-share-token)**（Java 报表/大屏）：分享 token 用硬编码 JWT 密钥签名，可离线伪造后访问 `testTransform`，脚本交给 GroovyClassLoader 执行，未认证 RCE。CVSS 9.8。影响 `≤1.7.1`，暂无官方修复版本，请下线公网入口或在网关层限制访问 `testTransform` 相关接口。
- **网络设备 OS（路由器）一批**，均附公开 PoC：[D-Link DIR-505 CVE-2026-120189](https://nvd.nist.gov/vuln/detail/CVE-2026-120189)（tftpd 文件名栈溢出，10.0）；WAVLINK 多型号命令注入 [CVE-2026-120195](https://nvd.nist.gov/vuln/detail/CVE-2026-120195) / [120198](https://nvd.nist.gov/vuln/detail/CVE-2026-120198)（10.0）及 120196/120197/120227/120228/120229/120230/120231（9.1–9.9）；[Oray 蒲公英 X5 Pro CVE-2026-120224 / 120225](https://nvd.nist.gov/vuln/detail/CVE-2026-120225)（≤7.6.1，越权调用 API / 配置恢复路径穿越致 root 执行，9.9 / 9.1）。均未见厂商修复说明；若机房/分支用到这些设备，关闭 WAN 侧管理并替换或隔离。
