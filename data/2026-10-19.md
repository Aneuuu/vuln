# 运维安全漏洞简报（2026-10-19）
Redis 一个 5 月已修复的漏洞被报告在野利用；F5 把上周 Nginx 漏洞上调为严重。
## 已被在野利用：Redis
- **[CVE-2026-25243](https://github.com/redis/redis/security/advisories/GHSA-c8h9-259x-jff4)** `RESTORE` double free 致 RCE，CVSS 8.8，利用代码已公开（第三方报道）。修复 6.2.22 / 7.2.14 / 7.4.9 / 8.2.6 / 8.4.3 / 8.6.3。缓解：`ACL SETUSER <user> -restore`，确认 6379 不暴露公网。[加拿大网络安全中心 AV26-423](https://www.cyber.gc.ca/en/alerts-advisories/redis-security-advisory-av26-423)
## 严重：Nginx 后续
- CVE-2026-15176 / 93479 / 97205 上调为严重，非默认配置下可未认证远程利用。还影响 F5 NGINX Ingress Controller、Gateway Fabric。升 1.30.6+ / 1.31.7+。[nginx 安全公告](https://nginx.org/en/security_advisories.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/f5-releases-out-of-band-patches-for-critical-nginx-vulnerabilities/)
## 高危
- **[CVE-2026-103314](https://access.redhat.com/security/cve/CVE-2026-103314)** RHACS Central SAML 重放，CVSS 7.4。
- **[CVE-2026-112368](https://jira.mongodb.org/browse/PHPC-276)** MongoDB PHP 驱动 BSON 无限递归崩溃，CVSS 7.5。
## 中危
- **[CVE-2026-112778](https://github.com/traefik/traefik/security/advisories/GHSA-rh7m-2m44-x32f)** Traefik K8s Ingress 跨命名空间引用，修复 2.11.46 / 3.6.17 / 3.7.1。
- **[CVE-2026-112210](https://access.redhat.com/security/cve/CVE-2026-112210)** RHEL rhc 符号链接本地提权。
