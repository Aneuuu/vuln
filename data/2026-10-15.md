# 运维安全漏洞简报（2026-10-15）
Atlassian 进入 CISA KEV（10/18 截止）；容器与 K8s 生态集中出了一批严重漏洞。
## 已被在野利用
- **[CVE-2026-21589](https://confluence.atlassian.com/security/cve-2026-21589-arbitrary-file-access-vulnerability-impacts-multiple-products-1870495748.html)** Atlassian Data Center 全系未认证任意文件读取，CVSS 9.3。Confluence 9.2.26 / 10.2.19，Jira 9.12.40 / 10.3.26 / 11.3.12，Bitbucket 9.4.26 / 10.2.8 / 10.5.1。
- **CVE-2026-111357** Ivanti Connect Secure 本地提权到 root。[Ivanti 公告](https://hub.ivanti.com/s/article/Security-Advisory-Ivanti-Connect-Secure-CVE-2026-104935)
- KEV 10/14 另新增 PAN-OS CVE-2026-0322、Cisco 安全邮件网关 CVE-2026-76519。
## 严重 / 高危：K8s 与容器
- **[CVE-2026-77459](https://github.com/advisories/GHSA-fmxq-cgp8-87wp)** Argo CD 删除 hook 绕过 AppProject，CVSS 9.9。修复 3.3.15 / 3.4.10 / 3.5.4。
- **[CVE-2026-77524](https://github.com/advisories/GHSA-637c-6jxx-4rwm)** KEDA 泄露 operator token，提权为集群管理员，CVSS 9.9。修复 2.21.0。
- **[CVE-2026-94603](https://github.com/advisories/GHSA-2cvf-wqm6-wr9g)** Podman checkpoint 镜像可关闭沙箱隔离，CVSS 10.0。修复 5.8.8 / 6.1.3。
- **[CVE-2026-47218](https://github.com/containerd/runwasi/security/advisories/GHSA-cc25-vq59-rcjx)** containerd runwasi 绕过 Wasm 校验执行原生代码，CVSS 9.3。修复 0.6.1。
- **[CVE-2026-95837](https://github.com/advisories/GHSA-p7v4-vr35-mj6f)** containerd 不可信 checkpoint 恢复后提权，CVSS 7.8。修复 2.2.7 / 2.3.4。
- **[CVE-2026-92982](https://access.redhat.com/security/cve/CVE-2026-92982)** Ansible Operator 模板注入，CVSS 8.5。
- **[CVE-2024-22031](https://github.com/rancher/rancher/security/advisories/GHSA-8h6m-wv39-239m)** Rancher 同名项目越权，CVSS 8.5。
## 高危：其他运维组件
- **[CVE-2026-9703](https://grafana.com/security/security-advisories/cve-2026-9703)** Grafana Viewer 可改 Loki 告警规则，CVSS 7.1。修复 12.3.9 / 12.4.6 / 13.0.4。
- **[Nginx UI](https://github.com/advisories/GHSA-9jww-cxg5-rj9m)**（0xJacky 面板，非 Nginx 本体）配置注入 RCE、二次验证绕过，最高 8.8。
- **[CVE-2026-110812](https://aws.amazon.com/security/security-bulletins/2026-136-aws/)** Amazon Neptune 反序列化 RCE，CVSS 9.4。升 1.5.0.0 或 1.4.8.1 / 1.4.7.1。
## 中低危
- OpenSSH 5 个漏洞（sftp 写出目录外、`%u` shell 注入等）。[RHSA-2026:82247](https://access.redhat.com/errata/RHSA-2026:82247)
- [CVE-2026-95838](https://github.com/advisories/GHSA-rp3h-jf77-q9p4) containerd 解包 DoS。修复 1.7.35 / 2.0.12 / 2.2.8 / 2.3.5。
- [CVE-2026-85747](https://github.com/advisories/GHSA-685w-q87j-wqw3) distribution 按 digest 拉取不校验，v3 修复 3.1.2。
## 其他
- 无新公告：Nginx 本体、Linux 内核、OpenSSL、Redis、MongoDB、Jenkins、K8s 核心组件。
