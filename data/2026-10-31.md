# 运维安全漏洞简报（2026-10-31）
头号事项：Canonical [LXD / MicroCloud CVE-2026-112816](https://discourse.ubuntu.com/t/security-advisory-critical-vulnerability-found-in-canonical-lxd-and-microcloud/90557)（CVSS 10.0）— HTTPS 客户端证书链校验不当，能摸到 LXD API 的攻击者可把任意已信任客户端公钥塞进中间证书冒充该身份，拿满集群与托管 VM 权限；MicroCloud 加入节点时也可被截获公钥后冒充。另外 [pgAdmin 4](https://nvd.nist.gov/vuln/detail/CVE-2026-116241) 一批（含 9.9 的 `\copy` 逃逸 RCE）、[OpenSearch SQL 插件反序列化 RCE](https://github.com/opensearch-project/sql/security/advisories/GHSA-r8cv-xvqm-4qj4)（8.7）、GitOps 工具 [Kargo 项目级 RBAC 越权](https://nvd.nist.gov/vuln/detail/CVE-2026-61850)（9.3）值得优先处理。CISA KEV 当日无新增条目；昨天入库的 Ivanti Connect Secure 利用链（CVE-2026-111357 截止 11-02）仍在倒计时。NVD 本窗口新发布约 394 条、CRITICAL 8 条（多为 WordPress 插件），lastMod CRITICAL 19 条含历史条目评分更新。
## 已被在野利用
- 无新增：CISA KEV 目录版本仍为 `2026.10.30`，`dateAdded=2026-10-31` 为 0。昨天进 KEV 的 [CVE-2026-111357 / CVE-2026-118527 Ivanti Connect Secure](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) 修复截止分别为 11-02（需取证）和 11-13，见昨日简报。
## 严重
- **[Canonical LXD / MicroCloud CVE-2026-112816](https://discourse.ubuntu.com/t/security-advisory-critical-vulnerability-found-in-canonical-lxd-and-microcloud/90557)**（虚拟化/容器 OS）：远程 mTLS 认证只比对客户端证书链里任意证书是否在信任库，未校验叶子证书持有私钥，未认证攻击者可冒充任意已信任 TLS 客户端，拿满集群与托管虚拟机权限；MicroCloud 场景可截获加入节点公钥后冒充。CVSS 10.0，未见在野利用报告。影响 `4.0.14` / `5.0.10` / `5.21.8` / `6.9` 及更早对应线，升到 `4.0.15` / `5.0.11` / `5.21.9` / `6.10.1`，见 [GHSA-pq55-m3w3-jh54](https://github.com/advisories/GHSA-pq55-m3w3-jh54)。LXD API 不要暴露到不可信网络。
- **[pgAdmin 4 CVE-2026-116241 等一批](https://nvd.nist.gov/vuln/detail/CVE-2026-116241)**：Import/Export 把查询包进 `psql \copy` 时括号/引号校验可被双引号标识符绕过，已认证用户可逃逸包装执行任意 SQL/命令，CVSS 9.9；另有登录锁定可被 Flask-Security `/login` 绕过致无限猜密码 [CVE-2026-116238](https://nvd.nist.gov/vuln/detail/CVE-2026-116238)（8.1）、未配密码文件时回退到服务账号 `~/.pgpass`/客户端证书 [CVE-2026-116247](https://nvd.nist.gov/vuln/detail/CVE-2026-116247)（8.2），以及中危的符号链接 TOCTOU、`--dbname` 连接串注入等。上游跟踪为待发 `9.19`（当前标签止于 `9.18`），临时勿把 pgAdmin 暴露公网、限制可登录用户，并避免在 server 模式用高权限 OS 账号跑服务。
- **[Kargo CVE-2026-61850](https://nvd.nist.gov/vuln/detail/CVE-2026-61850)**（K8s GitOps）：项目级 RBAC API 授权缺陷，已认证且仅有委托管理 Project Roles/ServiceAccounts 的用户可给自己或他人授予超出自身的权限。CVSS 9.3。影响 `0.6.0` 起至 `1.8.14` / `1.9.9` / `1.10.8` 之前，升到 `1.8.14` / `1.9.9` / `1.10.8`（或更新）。
- **[Thales Sentinel Keys Server CVE-2026-78403](https://supportportal.thalesgroup.com/csm?id=kb_article_view&sys_kb_id=50fc9f3b3b005f10bba8b41864e45a61&sysparm_article=KB0031216)**（Windows 许可服务）：HTTP 首字段长度未检 + 缺授权，可导致以 `NT AUTHORITY\SYSTEM` 远程代码执行，CVSS 9.8。影响低于 `1.3.8.0`，升到 `1.3.8.0` 及以上，管理口勿对公网开放。
- **[JetBrains IDE / Toolbox CVE-2026-118697](https://blog.jetbrains.com/security/2026/10/compromised-emudhra-certificates-ides/)**：`jetbrainsd` 信任了被滥用的中间证书，CVSS 9.0；同批 [CVE-2026-118696](https://nvd.nist.gov/vuln/detail/CVE-2026-118696)（8.0）见 JetBrains 公告。Toolbox 升到 `3.9.1` / `3.8.2`，IntelliJ IDEA 等到 `2026.3` / `2026.2.4` 等对应修复版（见 [issues-fixed](https://www.jetbrains.com/privacy-security/issues-fixed/)）。
- **[Erlang ssl_verify_fun CVE-2026-117666](https://github.com/deadtrickster/ssl_verify_fun.erl/security/advisories/GHSA-7gw2-hphm-c5px)**：部分标签通配符校验证书主机名时 `*` 可吞掉点号，中间人可冒充 TLS 对端，CVSS 9.1。按 [EEF 公告](https://cna.erlef.org/cves/CVE-2026-117666.html) 升级依赖该库的 Elixir/Erlang 应用。
- 另有 Flowise 沙箱逃逸 OS 命令执行 [CVE-2026-119978](https://github.com/advisories/GHSA-9gvv-qjj3-2p6g)（NVD 记 9.0/8.5 量级，需认证且 `ALLOW_BUILTIN_DEP=true`）→ 关注上游修复；ThingLinks / Bazarr / LMDeploy / OpenDeepWiki 等偏垂直产品的 9.x 未逐条展开。
## 高危
- **[OpenSearch SQL CVE-2026-63393](https://github.com/opensearch-project/sql/security/advisories/GHSA-r8cv-xvqm-4qj4)**：已认证、仅有基础读/搜索权限的用户可对 `plugins/sql` 传入恶意 `cursor`，触发不安全反序列化并在服务器执行任意代码，CVSS 8.7。影响 2.x `2.8.0.0`–`<2.19.6.0`、3.x `<3.7.0.0`，升到插件/仓库发布 `2.19.6.0` / `3.7.0.0`。跑 OpenSearch 且装了 SQL 插件的集群优先打。
- **[OSAC Kubernetes operator CVE-2026-62284](https://github.com/osac-project/osac-operator/security/advisories/GHSA-5w5g-j6hw-6p8f)**：`console-proxy` 解析带 `osac.openshift.io/remote-cluster-kubeconfig=true` 的 Secret kubeconfig 时未消毒 `exec` 凭据插件，可在 operator 权限下执行攻击者命令，CVSS 8.6。按上游提交升级 operator。
- **[Pi-hole CVE-2026-119336](https://github.com/pi-hole/pi-hole/security/advisories/GHSA-xch2-4qxw-g5vj)**：root 定时任务 `updatecheck.sh` 对 `pihole` 用户可控目录中的路径跟随符号链接做 `truncate`/`chmod`，本地 `pihole` 用户可提权破坏或种植 root 文件，CVSS 7.8。影响 `6.4.2` 至 `<6.5`，升到 `6.5`。
- **[Debian DSA-6597-1 dpdk](https://lists.debian.org/debian-security-announce/2026/msg00516.html)**（系统包）：DPDK 多条漏洞（CVE-2026-86561 等十余个），特制报文或恶意 guest 请求可导致拒绝服务或内存破坏。trixie 升到 `24.11.8-0+deb13u1`。
- 另有 JetBrains 配套 CVE-2026-118696（见上）、若干自托管 CMS/物联网平台 8.x 项未逐条收录。
## Java 生态

## Node.js 生态
