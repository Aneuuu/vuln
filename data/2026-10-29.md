# 运维安全漏洞简报（2026-10-29）
头号事项：CISA 10-29 把 GitLab CE/EE 的 [CVE-2026-97229](https://nvd.nist.gov/vuln/detail/CVE-2026-97229)（CVSS 10.0，未授权经 CI/CD 正则实现 RCE）和 Cisco ASA/FTD 的 [CVE-2026-76418](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-asaftd-tunnel-dos-s6mgkb75)（SSL VPN 未授权 DoS）加入 KEV，修复截止都是 11-01。另外 Jenkins 发了一批 13 个高危（升 `2.588` / LTS `2.580.2`），Juniper Session Smart Router、Sophos UTM 出了未授权 root 级漏洞，Apache Kafka 一次披露十多个漏洞（含 OAUTHBEARER 默认不验签）。NVD 窗口共 476 条，CVSS ≥9 的大多是 WordPress 插件与小众项目，本报只收运维/OS/网络设备相关项。
## 已被在野利用
- **[CVE-2026-97229 GitLab CE/EE CI/CD 正则整数溢出 RCE](https://nvd.nist.gov/vuln/detail/CVE-2026-97229)**：未认证用户可通过 CI/CD 配置里构造的正则在 GitLab 服务器上执行任意代码，CVSS 10.0。10-29 进 [CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)，截止 11-01，要求取证排查。影响 19.2–&lt;19.2.8、19.3–&lt;19.3.5、19.4–&lt;19.4.2，按 [GitLab 19.4.2 补丁公告](https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-4-2-released/) 升级。CISA 提示根因在 Ruby/Onigmo 正则，其他 Ruby 应用也可能受影响，见 [Ruby 官方说明](https://www.ruby-lang.org/en/news/2026/10/23/regexp-fixes-for-gitlab-cves)。
- **[CVE-2026-76418 Cisco Secure Firewall ASA / FTD SSL VPN 空指针 DoS](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-asaftd-tunnel-dos-s6mgkb75)**：tunnel group 配置了二次认证时，未认证远程攻击者发特制请求即可让设备重启，CVSS 8.6。10-29 进 KEV，截止 11-01。按 Cisco 公告升级，暴露 SSL 远程接入 VPN 的设备优先。
## 严重
- **[Juniper Session Smart Router / Conductor 一批](https://nvd.nist.gov/vuln/detail/CVE-2026-103409)**：未认证构造 URL 参数直接拿管理员权限 CVE-2026-103409（9.8）、Conductor AutomatedProvisioner 远程以 root 执行命令 [CVE-2026-103406](https://nvd.nist.gov/vuln/detail/CVE-2026-103406)（9.8），另有 DHCP 客户端栈溢出 RCE CVE-2026-103408（8.8）、AccessManager 命令注入、ConfigDirector 任意文件读写等多条 8.8。按 Juniper 公告升级，管理面不要暴露。
- **[Sophos UTM CVE-2026-118633](https://nvd.nist.gov/vuln/detail/CVE-2026-118633)**：邮件相关组件路径穿越，未认证远程攻击者持续打几分钟赢下竞争条件即可以 root 执行代码，CVSS 9.2，影响所有版本。按 Sophos 公告处置。
- **[Yamaha 无线路由 NWR100 CVE-2026-97854](https://nvd.nist.gov/vuln/detail/CVE-2026-97854)**：OS 命令注入，特制请求即可执行任意命令，CVSS 9.8；同设备配置导出文件可被未认证读取 CVE-2026-109822（7.1）。按 Yamaha/JPCERT 公告升级固件。
- **[D-Link DIR-505 CVE-2026-118579](https://nvd.nist.gov/vuln/detail/CVE-2026-118579)**：1.10B02 Web 管理 CGI 命令注入，CVSS 9.8。该型号较老，如还在用建议直接下线或替换。
- **[Echo（Go Web 框架）CVE-2026-118264](https://nvd.nist.gov/vuln/detail/CVE-2026-118264)**：Proxy 中间件在确认上游接受 WebSocket 升级前就建立原始隧道，可走私请求，CVSS 9.1；同批 CVE-2026-118262/118261/118260（8.2，资源耗尽）和 [CVE-2026-118650](https://github.com/advisories/GHSA-375p-5qhx-8wq4)（7.5，`%2F` 绕过 Static 路由中间件）。升到 Echo v4 `4.16.1` / v5 `5.4.1`。

- **[Samba vfs_ceph_rgw CVE-2026-109411](https://nvd.nist.gov/vuln/detail/CVE-2026-109411)**（系统包）：实验性 vfs_ceph_rgw 模块 `openat()` 访问控制绕过，已认证用户可读写受限文件，CVSS 8.1。只影响启用该模块的共享，等发行版更新。

- **[oapi-codegen CVE-2026-119028](https://nvd.nist.gov/vuln/detail/CVE-2026-119028)**（Go）：恶意 OpenAPI 文档可注入 Go 代码到生成结果，CVSS 8.8（另 CVE-2026-119027 7.7）。升到 `2.8.1`，别对不可信规范跑代码生成。

- **[OAuthLib CVE-2026-118669](https://nvd.nist.gov/vuln/detail/CVE-2026-118669)**（Python）：client_credentials / 密码模式授权可把客户端误认为机密客户端，CVSS 8.4。升到 `4.0.0`。

## Java 生态
- **[Apache Kafka 一批](https://kafka.apache.org/cve-list)**（NVD 暂未评分）：SASL/OAUTHBEARER 默认 `DefaultJwtValidator` 在未配 JWKS URL 时静默退回不验签，可伪造任意身份 CVE-2026-110985（CVE-2026-33557 修复不完整）；未配 expected issuer/audience 时不校验 iss/aud CVE-2026-110952；无任何授权的已认证用户可让 broker 读宿主文件或环境变量 CVE-2026-112375；Kafka Connect admin 监听器绕过认证 [CVE-2026-115644](http://www.openwall.com/lists/oss-security/2026/10/28/15)、validate 接口可明文解出 Config Provider 里的密钥 [CVE-2026-116593](http://www.openwall.com/lists/oss-security/2026/10/28/16)，另有多条反序列化/解压内存耗尽 DoS。升到 `4.2.2` / `4.3.2` / `4.4.0`；用 OAUTHBEARER 的请同时显式配置 `sasl.oauthbearer.jwks.endpoint.url` 和 expected issuer/audience。
- **[WildFly / JBoss EAP IIOP 三条](https://access.redhat.com/security/cve/CVE-2026-84725)**：EAP 带 `-secmgr` 时 openjdk-orb 会按攻击者给的 codebase URL 远程加载类 CVE-2026-84725（8.1）；IIOP 未校验传输层认证即接受身份断言，可冒充任意主体调用 @Remote EJB [CVE-2026-114488](https://access.redhat.com/security/cve/CVE-2026-114488)（7.4）；认证前反序列化 [CVE-2026-15564](https://access.redhat.com/security/cve/CVE-2026-15564)（7.4）。都在 3528 端口，按 Red Hat 更新升级，不用 IIOP 的话关掉或防火墙封住该端口。
