# 运维安全漏洞简报（2026-11-02）
头号事项：RHEL 8/9/10 昨晚起陆续放出 [CVE-2026-98432](https://nvd.nist.gov/vuln/detail/CVE-2026-98432) 内核补丁（CVSS 9.8，IPv4 TCP 连接建立阶段 use-after-free，未认证可达任意监听端口）— [RHSA-2026:93414](https://access.redhat.com/errata/RHSA-2026:93414) / [93412](https://access.redhat.com/errata/RHSA-2026:93412) / [93413](https://access.redhat.com/errata/RHSA-2026:93413)，打完必须重启；Ubuntu 各 LTS 仍无 USN。另外 Prefect [Prefab UI 沙箱逃逸](https://github.com/advisories/GHSA-3g72-rrqc-f76c)（CVE-2026-120338，CVSS 10.0）和自建 Web SSH [Termix 任意文件写](https://nvd.nist.gov/vuln/detail/CVE-2026-120322)（9.9，已有公开 PoC）值得当天处理。CISA KEV 无新增；[Ivanti Connect Secure CVE-2026-111357](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) 联邦修复截止就是今天（11-02）。NVD 本窗口新发布 118 条、CRITICAL 13 条（以 WAVLINK / Linksys 路由器命令注入为主），GHSA Maven / npm 生态无新增 High/Critical。
## 已被在野利用
- 无新增：CISA KEV 目录版本仍为 `2026.10.30`，`dateAdded=2026-11-02` 为 0。提醒：10-30 入库的 [CVE-2026-111357 Ivanti Connect Secure 缺失认证](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) 修复截止为 **11-02（今天）**，需按 CISA 要求做取证与补丁；同链路 CVE-2026-118527 截止 11-13。另有 Plex Media Server CVE-2026-96655 / 96652 截止 11-03，见 10-20 简报。CVE-2026-98432 **尚未**进 KEV，未见在野利用报告。
## 严重
- **[Linux 内核 CVE-2026-98432](https://nvd.nist.gov/vuln/detail/CVE-2026-98432)**（IPv4 TCP）：`tcp_v4_syn_recv_sock()` 把 `ireq_opt` 转给子套接字时未等 RCU grace period，重传 SYN 的另一 CPU 仍在读已被释放的 IP 选项，未认证攻击者对任意监听端口即可触发内核 UAF（内存破坏 / 崩溃，Red Hat 认为精确时序下可 RCE）。CVSS 9.8（内核 CNA / RHEL Critical），Ubuntu 内部标 High。影响自 4.4 起、含容器宿主机与 K8s 节点；上游修在 `5.10.272` / `5.15.223` / `6.1.190` / `6.6.159` / `6.12.113` / `6.18.56` / `7.2.10` / `7.3`。**RHEL 8** 升到 `kernel-4.18.0-553.182.1.el8_10`（[RHSA-2026:93414](https://access.redhat.com/errata/RHSA-2026:93414)），**RHEL 9** `5.14.0-687.64.1.el9_8`（[RHSA-2026:93412](https://access.redhat.com/errata/RHSA-2026:93412)），**RHEL 10** `6.12.0-211.72.1.el10_2`（[RHSA-2026:93413](https://access.redhat.com/errata/RHSA-2026:93413)），必须重启。Debian 已有 bookworm `6.1.190-1` / trixie `6.12.113-1`。**Ubuntu 22.04/24.04/26.04/26.10 仍为 Vulnerable / work in progress，无 USN**；未打补丁前可按 Red Hat [RHSB-2026-016](https://access.redhat.com/security/vulnerabilities/RHSB-2026-016) 用 nftables 丢弃带 IPv4 选项的入站 TCP（可能影响少数业务，先测）。容器镜像无法替代宿主机内核。
- **[Prefab UI CVE-2026-120338 / GHSA-3g72-rrqc-f76c](https://github.com/advisories/GHSA-3g72-rrqc-f76c)**（Prefect 生成式 UI / FastMCP）：文档声称隔离的 Pyodide+Deno 沙箱以 `--allow-read/write/net` 启动且把 Deno API 留在 JS 全局，调用方可经 `js` 模块读写宿主文件，甚至往 venv `site-packages` 写 `.pth` 持久化执行。CVSS 10.0（未认证 FastMCP）/ 9.9（已认证工具调用）。影响 `prefab-ui` `0.14.0`–`0.20.2`，升到 `0.21.0`（[PR #538](https://github.com/PrefectHQ/prefab/pull/538)）。未升级前不要对不可信客户端注册 `GenerativeUI`；宿主需安装 Deno 才暴露。
- **[Termix CVE-2026-120322](https://nvd.nist.gov/vuln/detail/CVE-2026-120322)**（自建 Web SSH）：`/plugin-api/file-manager/transferToHost` 的 `destPath` 路径穿越，已认证用户可向宿主任意路径写文件。CVSS 3.1 9.9，公开 PoC。影响 `2.9.0`–`2.9.2`；核心 `v26.10.0` 起与独立 File Manager 插件 `v1.0.0` 改为走 SFTP、去掉该捷径，请升到 `v26.10.0` / 当前 `v26.11.0`。
- **网络设备一批**（均附公开 PoC，未见厂商修复）：WAVLINK WN536AX6-A / WN553X1-B 多处命令注入与栈溢出 [CVE-2026-120276](https://nvd.nist.gov/vuln/detail/CVE-2026-120276) 等（9.9–10.0）；[Linksys E8450 CVE-2026-120283](https://nvd.nist.gov/vuln/detail/CVE-2026-120283)（`portal.cgi` `hidden_timezone` 栈溢出，10.0）；锐捷 RG-ES 系列交换机本地固件升级接口溢出 [CVE-2026-120241](https://nvd.nist.gov/vuln/detail/CVE-2026-120241)（7.5）。机房/分支若仍用这些型号，关闭 WAN 侧管理并隔离或替换。昨日 WAVLINK / D-Link / 蒲公英条目不再重复。
