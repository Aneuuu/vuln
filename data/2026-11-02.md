# 运维安全漏洞简报（2026-11-02）
头号事项：RHEL 8.10 内核出了 Critical 级更新 [RHSA-2026:93414](https://access.redhat.com/errata/RHSA-2026:93414)（CVE-2026-98432，ipv4 inet_opt 释放时机错误，Red Hat CVSS 9.8），kernel-rt 同步；同日 RHEL 8.4 的 FreeIPA/IdM 也有 Critical 更新（CVE-2026-76578 未认证 LDAP 客户端可拿管理员凭据，9.8）。边界设备方面，[Barracuda ESG 认证绕过](https://github.com/mandiant/Vulnerability-Disclosures/blob/master/2026/MNDT-2026-0042.md)（CVE-2026-116606，CVSS 4.0 9.3）可未认证导入配置，与同批 root 命令注入 CVE-2026-111560 可串成整机接管。Node.js 侧 [@fastify/http-proxy](https://github.com/fastify/fastify-http-proxy/security/advisories/GHSA-h3vp-4jfr-v364) 9.1 分路径限制绕过/SSRF；Java 侧 Apache Wicket 一次发了 10 个 CVE。CISA KEV 当日无新增。NVD 本窗口新发布 247 条、CRITICAL 21 条（以 WAVLINK 路由器命令注入为主）。
## 已被在野利用
- 无新增：CISA KEV 目录版本仍为 `2026.10.30`，`dateAdded=2026-11-02` 为 0。[CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)
## 严重
- **[RHEL 内核 CVE-2026-98432](https://access.redhat.com/errata/RHSA-2026:93414)**（Critical）：ipv4 在 RCU 宽限期前释放 inet_opt / ireq_opt 导致内存安全问题，Red Hat CVSS 3.1 9.8。RHEL 8.10 升到 `kernel-4.18.0-553.182.1.el8_10`，kernel-rt 见 [RHSA-2026:93415](https://access.redhat.com/errata/RHSA-2026:93415)（`553.182.1.rt7.523`）。同日 RHEL 10.2 [RHSA-2026:93413](https://access.redhat.com/errata/RHSA-2026:93413)（`6.12.0-211.72.1.el10_2`）也包含该 CVE；RHEL 9.8 [RHSA-2026:93412](https://access.redhat.com/errata/RHSA-2026:93412)（`5.14.0-687.64.1.el9_8`）为 Important 批次。需重启生效。
- **[FreeIPA/IdM RHSA-2026:93452](https://access.redhat.com/errata/RHSA-2026:93452)**（Critical，RHEL 8.4 idm:DL1 模块）：CVE-2026-76578 未认证 LDAP 客户端借 self-managed-token ACI 获取管理员凭据（9.8）、CVE-2026-11861 跨信任冒名获取 TGS（9.6）、CVE-2026-73197 未认证 DoS（7.5）等 8 个 CVE。用 IPA 做 LDAP/Kerberos 的环境尽快升级。
- **[Barracuda ESG CVE-2026-116606](https://trust.barracuda.com/security/pre-authentication-authorization-bypass-command-injection)**：未认证调用配置导入，恢复伪造备份改全局配置，CVSS 4.0 9.3，修复 ESG 9.4.0.030。同批 [CVE-2026-111560](https://github.com/mandiant/Vulnerability-Disclosures/blob/master/2026/MNDT-2026-0041.md)（8.6）为管理员时区字段命令注入、以 root 执行，影响 ESG ≤ 9.4.0.27、LB ADC ≤ 6.4.0、WAF ≤ 11.0.1、WSG ≤ 16.1.100.100、BMA ≤ 5.5.4.0、WCC ≤ 2.2.1。目前未见在野利用报告。
- **[Control Web Panel CVE-2026-73696](https://www.vulncheck.com/advisories/control-web-panel-cwp-execution-after-redirect-in-cwpuserindex)**（CentOS/RHEL 系主机面板）：用户面板跳转后未 exit，未认证可绕过登录，CVSS 9.1，修复 webpanel 1.12；同批 CVE-2026-73695 本地文件包含、CVE-2026-73697 phpini_editor 任意写/命令注入（均 8.8），修复 1.16。[CWP 更新日志](https://control-webpanel.com/changelog)
- **[WSO2 CVE-2025-11969](https://security.docs.wso2.com/en/latest/security-announcements/security-advisories/2026/WSO2-2025-4733/)**：System REST API 越权，低权限角色可执行管理操作，CVSS 9.4（经 API Gateway 暴露的 API 不受影响）。
- **[Prefab UI CVE-2026-120338](https://github.com/PrefectHQ/prefab/pull/538)**（Python）：Generative UI 沙箱以不受限的 Deno 权限运行，调用者提供的代码可读写服务器文件，CVSS 10.0，影响 0.14.0–0.20.2。
- **[Termix CVE-2026-120322](https://vuldb.com/cve/CVE-2026-120322)**（自托管 SSH/服务器管理面板）：`transferToHost` 路径穿越任意写，CVSS 9.9，PoC 已公开；文件管理插件 v1.0.0 / 核心 v26.10.0 已去掉该路径。
- 网络设备类（影响设备操作系统）：WAVLINK WN553X1-B / WN536AX6-A / WN551X3-A 多个 `/bin/ioos`、`/protocol.csp` 命令注入与栈溢出（CVE-2026-120238/120239/120240/120276/120277/120279/120280/120281/120282/120344/120345，9.9–10.0），Linksys E8450 `portal.cgi` 栈溢出（CVE-2026-120283，10.0），厂商均未回应、暂无修复，建议勿将管理界面暴露公网。[NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-120276)
