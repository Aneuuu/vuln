# 运维安全漏洞简报（2026-11-03）
头号事项：CISA KEV 新增 [CVE-2026-119977](https://nvd.nist.gov/vuln/detail/CVE-2026-119977) WordPress Core 升级窗口 TOCTOU 可未认证 RCE（已在野，联邦截止 11-06）。容器平台侧 [Rancher Fleet CVE-2026-94290](https://github.com/rancher/fleet/security/advisories/GHSA-qfmw-gw96-ffcr)（9.1）可提权至管理集群 cluster-admin，同批 meta proxy [CVE-2026-88811](https://github.com/rancher/rancher/security/advisories/GHSA-x82x-2qj6-5rm2)（9.1）凭据泄露；[kaniko CVE-2026-105769](https://github.com/chainguard-forks/kaniko/security/advisories/GHSA-5q7h-w9jf-cx97)（9.3）仿冒 ACR 主机可窃取 Azure 令牌。Ubuntu 当日大批内核 USN 与 [USN-8972-1 HAProxy](https://ubuntu.com/security/notices/USN-8972-1) DoS；Grafana Mimir [CVE-2026-81938](https://nvd.nist.gov/vuln/detail/CVE-2026-81938)（7.7）。Java / Node.js 常用栈本窗口无高危以上新漏洞。
## 已被在野利用
- **[CVE-2026-119977](https://nvd.nist.gov/vuln/detail/CVE-2026-119977) WordPress Core（CISA KEV 新增）**：全包升级窗口 TOCTOU 竞态（CWE-367），未认证攻击者可在 `wp-content/upgrade/` 可预测暂存路径中触达 `setup-config.php` 并在升级间隙执行代码。影响 4.7.0–7.1.3；修复 7.1.4（及各分支回移，如 7.0.8 / 6.9.11 / … / 4.7.39）。Wordfence CVSS 3.1 **8.1（High）**；**已在野利用**（CISA `dateAdded=2026-11-03`，联邦截止日期 2026-11-06，需取证分诊）。缓解：先在 Web 层拒绝访问 `wp-content/upgrade/`，再升级；审计该路径下 PHP/`setup-config.php` 请求与异常管理员/插件。[CISA 公告](https://www.cisa.gov/news-events/alerts/2026/11/03/cisa-adds-one-known-exploited-vulnerability-catalog) · [WordPress 7.1.4](https://wordpress.org/news/2026/10/wordpress-7-1-4)

## 严重
- **[CVE-2026-94290](https://nvd.nist.gov/vuln/detail/CVE-2026-94290) / [GHSA-qfmw-gw96-ffcr](https://github.com/rancher/fleet/security/advisories/GHSA-qfmw-gw96-ffcr) SUSE Rancher Fleet**：agent 管理控制器未限制 Cluster 可引用的 kubeconfig Secret，普通 `user` 全局角色即可把 Fleet Cluster 绑到管理集群管理凭据，提权至 **local cluster-admin**（波及全部下游集群密钥）。CVSS 3.1 **9.1 Critical**；未标在野。影响 Fleet ≥0.16.0/<0.16.3、≥0.15.0/<0.15.8、≥0.14.0/<0.14.12、≥0.13.0/<0.13.17；修复 Fleet **0.16.3 / 0.15.8 / 0.14.12 / 0.13.17**，Rancher **v2.15.3 / v2.14.7 / v2.13.11 / v2.12.15**（与捆绑 Fleet 一并升级）。临时：收回普通用户创建 `fleetworkspaces` 权限、限制非系统命名空间写 `clusters`。
- **[CVE-2026-88811](https://nvd.nist.gov/vuln/detail/CVE-2026-88811) / [GHSA-x82x-2qj6-5rm2](https://github.com/rancher/rancher/security/advisories/GHSA-x82x-2qj6-5rm2) Rancher Manager meta proxy**：转发至第三方云厂商主机时未稳定剥离调用方 Rancher 会话/Token，可致凭据泄露。CVSS 3.1 **9.1 Critical**；未标在野。影响 Rancher 2.15.0–<2.15.3、2.14.0–<2.14.7、2.13.0–<2.13.11 等；修复同上 **v2.15.3 / v2.14.7 / v2.13.11 / v2.12.15 / v2.11.19**。
- **[CVE-2026-105769](https://nvd.nist.gov/vuln/detail/CVE-2026-105769) / [GHSA-5q7h-w9jf-cx97](https://github.com/chainguard-forks/kaniko/security/advisories/GHSA-5q7h-w9jf-cx97) kaniko**：ACR 凭据助手用未锚定正则判定主机名，Dockerfile 引用形如 `x.azurecr.io.attacker.com` 的仿冒仓库即可把构建机 Entra ID（ARM）访问令牌 POST 到攻击者 `/oauth2/exchange`（无需 RUN/push）。CVSS 3.1 **9.3 Critical**；未标在野。**<1.25.20** 受影响，升级 **≥1.25.20** 并重建 executor/warmer。
- **[CVE-2026-116769](https://nvd.nist.gov/vuln/detail/CVE-2026-116769) Absolute Secure Access**：认证绕过，攻击者可经服务端修改客户端安全设置。CVSS 4.0 **9.3 Critical**；影响 13.0 起至 **14.61 之前**；升级至厂商修复版。[Absolute 公告](https://www.absolute.com/platform/security-information/vulnerability-archive/cve-2026-116769)
- **[CVE-2026-106803](https://nvd.nist.gov/vuln/detail/CVE-2026-106803) Kamailio**：`ims_registrar_pcscf` 处理恶意 `application/reginfo+xml` NOTIFY 时 `process_contact()` 栈溢出，未认证可致 P-CSCF 进程崩溃（DoS）。报告 CVSS 3.1 **9.8 Critical**；影响 **v6.1.3 / v6.1.4**；按上游 [PR #4958](https://github.com/kamailio/kamailio/pull/4958) / [issue #4954](https://github.com/kamailio/kamailio/issues/4954) 合入修复后升级。未标在野。
- **[CVE-2026-102435](https://nvd.nist.gov/vuln/detail/CVE-2026-102435) WordPress Ultra Addons for Contact Form 7**：未认证任意文件删除（可删 `wp-config.php` 通向 RCE），需 PDF Generator 插件启用。CVSS 3.1 **9.8 Critical**；≤3.5.54；按 Wordfence/插件变更集升级。未标在野。
- **[RHSA-2026:94109](https://access.redhat.com/errata/RHSA-2026:94109) RHEL 9.4 Update Services for SAP Solutions 内核（Critical）**：含 **[CVE-2026-98432](https://nvd.nist.gov/vuln/detail/CVE-2026-98432)**（IPv4 TCP `inet_opt`/`ireq_opt` UAF，内核 CNA CVSS **9.8**，可远程未认证利用路径）等。固定包 **`kernel-5.14.0-427.161.1.el9_4`**，需重启。补充：主流 RHEL 8.10/9.8/10.2 修复已于 11-01/11-02 窗口见报；Ubuntu 官方稳定通道本窗口 **USN-8959 等批次仍不含 98432**，公开报道称修复仍在 proposed/测试通道，关注后续 USN。
