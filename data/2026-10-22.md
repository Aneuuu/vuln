# 运维安全漏洞简报（2026-10-22）
GitLab 发紧急补丁修复未认证 RCE（CVE-2026-110264，CVSS 10.0），自建实例请马上升级；Cisco Expressway 未认证 root 命令执行（9.8）、Node.js 10 月安全版本（Brotli 越界写 RCE 等）、Next.js 图片优化未认证 RCE 紧随其后。RHEL 全线推出 PHP 严重漏洞修复包。全量扫 NVD 当日 516 条（严重 45 条），CISA KEV 当天无新增。
## 已被在野利用
- 无新公告：CISA KEV 截至 10-22 无新增（最新一批为 10-20 的 6 条，已报）；NVD 当日 45 条严重级均未标 KEV。[CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)
## 严重
- **[GitLab CE/EE CVE-2026-110264](https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-5-1-released/)**：正则编译器整数溢出，特定条件下未认证即可在服务器上执行任意代码，CVSS 10.0（GitLab 官方 Critical）。影响 7.0 起全部版本，升到 19.5.1 / 19.4.3 / 19.3.6 / 19.2.9 / 19.1.9 / 19.0.10 / 18.11.13；同批还有 OmniAuth-LDAP 自动关联认证绕过、OAuth/OIDC 发现端点缓存投毒两个高危。GitLab.com 已修复。
- **[Cisco Expressway CVE-2026-76466](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-vcs-static-cred-hr7EWZ8t)**：数据库服务使用持久 cookie，集群 TLS 校验模式下又不验证客户端证书，未认证远程攻击者可以 root 执行系统命令，CVSS 9.8。Expressway-C / E 均受影响，无缓解措施，按公告升级。
- **[Cisco 统一通信产品 10 月加固版本](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-voice-hardening-twgbH9e3)**：CVE-2026-76473 / 76474（9.8）、76475（9.3）等 8 个，涉及 Unified CM、IM&P、SME、Unity Connection、Emergency Responder、Prime Collaboration Deployment，无缓解措施，按公告升级。
- **[Node.js 10 月安全版本](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases)**：Brotli 解码越界写 CVE-2026-111497（NVD 9.2，可能 RCE），另有 TLS 证书主机名校验绕过 CVE-2026-105483 / 106069、`dns.resolve` NUL 截断 CVE-2026-105482（均 high）等 10 个。升到 26.12.1 / 24.22.1 / 22.23.4；系统里单独装的 Brotli 库升到 1.0.10 / 1.1.1 / 1.2.1。RHEL 9 `nodejs26` 已出包（[RHSA-2026:87703](https://access.redhat.com/errata/RHSA-2026:87703)）。
- **[Next.js 图片优化未认证 RCE GHSA-2464-fhr4-w9xw](https://github.com/advisories/GHSA-2464-fhr4-w9xw)**（GitHub 定级 Critical，暂无 CVE）：上游 `sharp` 内存漏洞，在 glibc Linux 上处理 SVG 可远程执行代码。影响 10.0.0–15.5.27、16.0.0–16.4.0，升到 15.5.28 / 16.4.1，或确保 `sharp` ≥ 0.35.5。
- **[RHEL PHP 严重漏洞修复包](https://access.redhat.com/errata/RHSA-2026:87079)**：昨天报的 PHP 未认证 RCE CVE-2026-109618 / 109619（9.8）今天 RHEL 全线出包，另含 SOAP 解析递归 DoS CVE-2026-91765（7.5）。RHEL 9 `php:8.3` 模块 8.3.36（RHSA-2026:87079）、`php:8.2` 8.2.35（87072）、自带 php 8.0.30-8.el9_8.1（87151）；RHEL 8 `php:8.2` 8.2.35（87073）；RHEL 10 php 8.3.36 / php8.4 8.4.27（87070 / 87071）。升级后重启 php-fpm / httpd。
- **[Splunk Enterprise SVD-2026-1008](https://advisory.splunk.com/advisories/SVD-2026-1008) / [SOAR SVD-2026-1011](https://advisory.splunk.com/advisories/SVD-2026-1011)**：昨天按高危报过，今天 NVD 入库，最高分其实是 9.9（CVE-2026-76299 访问控制、76302、SOAR 76531）。Enterprise 升到 10.4.4 / 10.2.8 / 10.0.11 / 9.4.16，SOAR 升到 8.7.0。
- **[Apache Pulsar Manager CVE-2026-105944](https://pulsar.apache.org/security/CVE-2026-105944/)**：未认证即可创建超级管理员，代理到集群的 admin API 也不鉴权，CVSS 4.0 10.0。0.1.0–0.4.0 全部受影响，项目已 EOL、不会修复，建议下线或只放内网并加前置认证。
- **[Apache Pulsar CVE-2026-105869](https://pulsar.apache.org/security/CVE-2026-105869/)**：`MultiRolesTokenAuthorizationProvider` 不验签 JWT，配了 `anonymousUserRole` 时可伪造角色，CVSS 4.0 9.2。影响 2.8.1 至 4.0.14 之前、4.1.0 至 4.2.5 之前，升到 4.0.14 / 4.2.5；临时把 `strictAuthMethod` 设为 true 或清空 `anonymousUserRole`。
