# 运维安全漏洞简报（2026-10-26）
头号事项：CISA 把 PHP「php2shell」两条 Critical（CVE-2026-109618 / 109619）打进 KEV，确认在野利用，联邦修复截止 10-29，公网 PHP 须立即升级并做取证排查。同日 HashiCorp 连发 Consul / consul-k8s 多条授权绕过（含 9.9），FortiSandbox 未认证绕过、Google MCP Toolbox 任意读写、Rust `zip` 双头解析 RCE 等 Critical 挂上 NVD。全量扫 NVD 窗口约 808 条（严重 26 条），本报只收运维/OS/云与网络设备相关。
## 已被在野利用
- **[CVE-2026-109618](https://nvd.nist.gov/vuln/detail/CVE-2026-109618) / [CVE-2026-109619](https://nvd.nist.gov/vuln/detail/CVE-2026-109619) PHP「php2shell」**：内存破坏与陈旧请求状态，未认证 RCE（NVD 约 9.8）。影响所有对外提供 Web 请求的 PHP（Apache mod_php 风险最高，以及 PHP-FPM、php-cgi、FrankenPHP、LiteSpeed）。修复：`8.5.12` / `8.4.27` / `8.3.36` / `8.2.35`。[CISA KEV 10-26](https://www.cisa.gov/news-events/alerts/2026/10/26/cisa-adds-two-known-exploited-vulnerabilities-catalog)；[CISA 告警（已更新）](https://www.cisa.gov/news-events/alerts/2026/10/21/critical-vulnerabilities-php-require-immediate-patching)。BOD 26-04 要求打补丁前做取证排查；公网实例优先。
## 严重
- **[Consul-k8s CVE-2026-110720](https://discuss.hashicorp.com/t/hcsec-2026-50-consul-k8s-vulnerable-to-a-cross-namespace-authorization-bypass-in-component-acl-binding-rules/77915)**（HCSEC-2026-50）：组件 ACL binding 跨命名空间授权绕过，可拿到升高的 Consul 权限，CVSS 9.9。影响 `0.42.0`–`2.0.4`，且 `global.acls.manageSystemACLs=true` 时；修复 `2.1.0` / `1.8.18`。
- **[Rust zip CVE-2026-115905](https://github.com/zip-rs/zip2/security/advisories/GHSA-m665-v7pm-7grj)**：`ZipArchive` 与 `ZipStreamReader` 双头不一致（Zip Cloaking），可绕过网关扫描并任意覆盖文件/RCE，CVSS 4.0 10.0。`<= 9.0.4` → `9.0.5`。凡用流式解压用户上传 ZIP 的服务优先排查。
- **[FortiSandbox CVE-2026-107656](https://fortiguard.fortinet.com/psirt/FG-IR-26-185)**（FG-IR-26-185）：GUI 认证绕过，未认证可执行未授权代码/命令，CVSS 约 9.6–9.8。5.0.0–5.0.6 → ≥5.0.7；4.4.0–4.4.9 → ≥4.4.10；4.2 / PaaS 4.4 需迁移到已修复线。未见在野利用报告。
- **[Google Cloud MCP Toolbox CVE-2026-93328](https://www.cve.org/CVERecord?id=CVE-2026-93328)**：cloud-storage source 路径穿越 + 缺授权，未认证可把宿主机文件外泄到任意 GCS bucket 并覆盖本地文件，CVSS 4.0 9.3。影响 `1.2.0`–`1.4.0` → ≥`1.5.0`，并配置 `allowedBuckets` / `allowedLocalRoots`。
- **[Burrito（K8s Terraform 算子）CVE-2026-102649](https://github.com/padok-team/burrito/security/advisories/GHSA-7m68-72r6-3jx8)**：`webhookSecret` 为空时接受未签名 GitHub/GitLab webhook，可触发未授权 Terraform plan，CVSS 9.9。&lt; `0.13.0` → `0.13.0`；务必配置非空 webhook 密钥。
- **[OpenHands Software Agent SDK CVE-2026-112346](https://github.com/OpenHands/software-agent-sdk/releases/tag/v1.52.0)**：沙箱 Agent Server 默认绑 `0.0.0.0` 且无认证，可达端口即可未认证 RCE（容器内 root），CVSS 9.8。&lt; `1.52.0` → ≥`1.52.0`；勿把沙箱端口暴露公网。
- **[Avocent ACS8000 CVE-2026-65184](https://www.runzero.com/advisories/avocent-acs8000-wsserver-cmdinj-cve-2026-65184)**：`wsserver` 终端桥命令注入，CVSS 9.8（串口/带外管理设备）。按厂商/公告缓解，限制管理面可达性。
- **[TOTOLINK A950RG](https://nvd.nist.gov/vuln/detail/CVE-2026-116508)**：同日多条 Critical（CVE-2026-116504/505/506/508，最高 10.0）命令注入/栈溢出。停用公网管理口或换固件；家庭/边缘路由若在网段需立即隔离。
- **[boneIO black_debian_images CVE-2026-77055](https://cert.pl/en/posts/2026/10/CVE-2026-77052)**：镜像给 boneio 用户免密 sudo + docker 组，本地可提权 root，CVSS 4.0 9.3。升到 boneio `1.6.0`（含迁移去掉特权）。
- **[Esri ArcGIS Server CVE-2026-10757](https://www.esri.com/arcgis-blog/products/trust-arcgis/administration/october-2026-arcgis-security-bulletin)**：SQL 注入，CVSS 9.8；Windows/Linux ≤12.1，按 10 月公告打补丁；服务若配成 public 风险更高。
