# 运维安全漏洞简报（2026-10-27）
头号事项：CISA 10-27 把 Google Brotli CVE-2026-111497 和 Adobe Commerce/Magento CVE-2026-48356 加入 KEV，确认在野利用（修复截止 11-10）。Brotli 是各发行版自带的系统库，上周 DSA-6582、前天 USN-8956-1 已出补丁，没升的请立即升。另有 Supermicro BMC IPMI 一批漏洞（最高 9.8），Hitachi JP1 / HiRDB 一批 9.8，NVIDIA NeMo Agent Toolkit 10.0。全量扫 NVD 窗口约 936 条（CVSS ≥9 约 39 条，大部分为 Hitachi 批量、TOTOLINK 及昨日已报项），本报只收运维/OS/云与网络设备相关的新项。
## 已被在野利用
- **[CVE-2026-111497 Google Brotli](https://nvd.nist.gov/vuln/detail/CVE-2026-111497)**：解码器未检查返回值，畸形压缩流可破坏相邻解码状态内存、泄露内存、DoS，可能 RCE（CNA CVSS 4.0 9.2）。10-27 进 [CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)，截止 11-10。上游修复 [brotli v1.2.1](https://github.com/google/brotli/releases/tag/v1.2.1)；系统包按 [Ubuntu USN-8956-1](https://ubuntu.com/security/notices/USN-8956-1) / [Debian DSA-6582-1](https://lists.debian.org/debian-security-announce/2026/msg00498.html) 升 `libbrotli1` 等，并排查内嵌 brotli 的 Nginx 模块、Node.js、Python 包等。
- **[CVE-2026-48356 Adobe Commerce / Magento](https://www.adobe.com/trust/security/products/commerce/apsb26-73.html)**：危险类型文件任意上传，可导致代码执行，CVSS 9.3（7 月公布，10-27 新进 KEV）。按 APSB26-73 打补丁，截止 11-10；跑 Magento 的服务器请同时做 Webshell 排查。
## 严重
- **[Supermicro BMC IPMI（10-26 公告）](https://www.supermicro.com/en/support/security_BMC_IPMI_Oct_2026_1)**：[CVE-2026-18450](https://nvd.nist.gov/vuln/detail/CVE-2026-18450) 活跃 RMCP+ 会话里接受未保护的 IPMI 命令，可执行任意命令，CVSS 9.8；同批还有 CVE-2026-65220 RAKP+ 提权到管理员（8.8）、CVE-2026-18449 SMCRAKP 硬编码密钥（7.5）、CVE-2026-65219（7.4）、CVE-2026-65211（7.2）等共 8 条。影响 X11–X14、H11–H14 等大量主板，需升级 BMC 固件（各型号修复版本见公告）。厂商称未见在野利用。缓解：BMC/IPMI 口只放带外管理网，禁用公网 623/UDP。
- **[NVIDIA NeMo Agent Toolkit CVE-2026-65145](https://github.com/NVIDIA/product-security/tree/main/2026/5912)**：缺认证，可导致代码执行、提权等，CVSS 10.0；同批 CVE-2026-65151 SQL 注入（8.4）。按 NVIDIA 公告升级。
- **[Hitachi JP1 / HiRDB 一批](https://nvd.nist.gov/vuln/detail/CVE-2026-82116)**：HiRDB Server 缺认证、认证绕过、OS 命令注入、栈/堆溢出（CVE-2026-82116～82120、82122，最高 9.8），修到 10-12-01 等；JP1/Automatic Job Management System 3 认证绕过与溢出（[CVE-2026-76938](https://nvd.nist.gov/vuln/detail/CVE-2026-76938) 等，9.8），Manager/Agent 修到 13-50-31；JP1/Base 堆溢出 [CVE-2026-86574](https://nvd.nist.gov/vuln/detail/CVE-2026-86574)（9.8）修到 12-50-54。用到 JP1 作业调度的请跟进。
- **[Kener CVE-2026-116747](https://nvd.nist.gov/vuln/detail/CVE-2026-116747)**（开源状态页）：`KENER_SECRET_KEY` 为空时回落硬编码 `DUMMY_SECRET`，可伪造管理员会话，CVSS 4.0 9.2。3.0.0–&lt;4.1.10 → `4.1.10`，并设置随机密钥。
- **[Eclipse ioFog Operator CVE-2026-115216](https://github.com/eclipse-iofog/iofog-operator/releases/tag/v3.9.2)**（K8s 算子）：访问 Controller API 和 OIDC 时关闭了 TLS 证书校验，中间人可窃取 OAuth client secret / 管理员密码，CVSS 4.0 9.1。3.8.0–&lt;3.9.2 → `3.9.2`，升级后轮换凭据。
- **[@fastify/express CVE-2026-112362](https://github.com/fastify/fastify-express/security/advisories/GHSA-6h42-57hq-9746)**（Node.js）：开启 `ignoreDuplicateSlashes` 时可绕过路径作用域的 Express 中间件（如鉴权），CVSS 9.1。影响 4.0.5–4.0.8，按公告升级。
- **[Authlib CVE-2026-96760](https://github.com/advisories/GHSA-6v38-4h7w-rj9h)**（Python）：JWS JSON 反序列化接受空签名，CVSS 9.1；同批 [CVE-2026-114615](https://github.com/advisories/GHSA-7vr2-2fgp-9w7p) 算法混淆 HMAC 伪造（7.4）。`<= 1.8.0` → `1.9.0`。
- **[Ajenti CVE-2026-27975](https://github.com/advisories/GHSA-vcw3-r3fx-j444)**（服务器管理面板）：潜在 RCE，CVSS 3.1 9.8。`aj` &lt; `2.2.13` → `2.2.13`；面板勿暴露公网。

- **[Ubiquiti airMAX / LTU 安全公告 071](https://uisp.community.ui.com/releases/Security-Advisory-Bulletin-071/7d4d42cf-09e4-44d3-9c19-649cac8c6af3)**：CVE-2026-116837 相邻网络堆溢出 RCE、CVE-2026-116838 CSRF 命令注入等（8.8）。升级设备固件。
- **[MongoDB Python 驱动 pymongo CVE-2026-106435](https://github.com/advisories/GHSA-98qm-wvgf-w4cf)**：畸形 BSON Regex 越界读，CVSS 4.0 8.2。3.9.0–4.18.2 → `4.18.3`。

- **[GitPython 一批](https://github.com/advisories/GHSA-f9j4-qggq-h239)**：`Remote.pull()` refspec 绕过 `--upload-pack` 防护可执行命令（8.1）、分支名任意文件读等。3.1.30–&lt;3.2.0 → `3.2.0`。

- **[Datadog dd-trace-py](https://github.com/advisories/GHSA-p3m5-h5v9-vqj6)**：IAST 插桩可致应用 DoS（CVE-2026-116589，8.2，→ `4.15.5`）；查询串混淆正则 ReDoS（CVE-2026-116588，8.7）。
- **[snappy-java CVE-2026-93451](https://github.com/advisories/GHSA-gwq9-9ffj-mvrv)**（Java，Kafka/Spark 常见依赖）：typed-array 解压堆溢出，CVSS 7.5。`<= 1.1.10.8` → `1.1.10.9`。
- **[Apple macOS 追加](https://nvd.nist.gov/vuln/detail/CVE-2026-112427)**：CVE-2026-112427 远程认证问题可致代码执行（8.1），修于 macOS Golden Gate 27.2（与昨日 Apple 批次同一更新）。

## 中危

- **[Ubuntu USN-8957-1 authd](https://ubuntu.com/security/notices/USN-8957-1)**：从身份提供方匹配账户时校验不严，可能拿到其他用户的本地账户和文件。用 authd 接 Entra ID / Google 登录的 Ubuntu 主机请升级。
