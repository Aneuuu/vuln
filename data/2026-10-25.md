# 运维安全漏洞简报（2026-10-23 至 10-26 周末）
CISA 于 10-23 把两条 Critical 打进 KEV：Arista VeloCloud Orchestrator SQL 注入（官方确认在野利用）与 Nextcloud 内嵌 Collabora CODE 未认证命令注入。同期还有 Incus 宿主机任意写、Wasmtime 沙箱逃逸、Azure 云侧 K8s/App Proxy 提权（微软已代修）、OpenWrt odhcpd 堆溢出，以及 RHEL 8 内核 / Grafana / OpenShift Builds 等补丁。NVD 窗口内新发严重级约 50+ 条，本报只收运维/OS 相关；周末合并至周日日期。
## 已被在野利用
- **[Arista VeloCloud Orchestrator CVE-2026-114625](https://www.arista.com/en/support/advisories-notices/security-advisory/24838-security-advisory-0199)**：已认证低权限用户可经 SQL 注入拿到 operator/超管能力并影响宿主机，CVSS 3.1 9.9 / 4.0 9.4。官方确认主动利用，IOC IP：`74.82.197.86`、`38.54.50.151`。[CISA KEV 10-23](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)。影响 on-prem VCO 5.2.x &lt; 5.2.3.18、6.1.x &lt; 6.1.3.10、6.4.x &lt; 6.4.2.12；升到对应修复版，并限制管理口、查日志。
- **[Collabora Online – Built-in CODE Server CVE-2026-110447](https://github.com/CollaboraOnline/online/security/advisories/GHSA-g3vx-3m76-fghh)**：Nextcloud 的 `richdocumentscode` 在内嵌 CODE 未运行时（重启/升级/崩溃窗口）可通过 `proxy.php` 未认证 OS 命令注入，CVSS 4.0 9.2。[CISA KEV 10-23](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)。升到 ≥ 26.4.303，或卸掉该 app；仅禁用 app 不够。独立 Collabora Online 不受影响。
## 严重
- **[Incus 任意宿主机写文件](https://github.com/lxc/incus/security/advisories)**：[CVE-2026-115375](https://nvd.nist.gov/vuln/detail/CVE-2026-115375) 备份依赖卷名路径穿越（9.9，影响 7.0.0–7.0.1 / 7.1.0–7.4.x）；[CVE-2026-115377](https://nvd.nist.gov/vuln/detail/CVE-2026-115377) 迁移流符号链接任意写（9.9，&lt;6.0.7、6.1–7.0.1、7.1–7.4.x）。均可导致 root 写任意路径、完全沦陷。升到 6.0.7 / 7.0.2 / 7.5.0；仅信任可创建实例的客户端。
- **[Wasmtime / Cranelift 沙箱逃逸](https://github.com/bytecodealliance/wasmtime/security/advisories)**：[CVE-2026-115384](https://nvd.nist.gov/vuln/detail/CVE-2026-115384) 异步回调栈溢出（9.9，39.0.0–48.0.3 / 49.0.0–49.0.1 → 48.0.4 / 49.0.2）；[CVE-2026-115889](https://github.com/bytecodealliance/wasmtime/security/advisories/GHSA-897f-g5gm-fmxm) SSA 位打包溢出误编译（9.9，&lt;36.0.19 与 37.x–42.x → 36.0.19 或 ≥43）；[CVE-2026-115893](https://nvd.nist.gov/vuln/detail/CVE-2026-115893) aarch64 大 `br_table` 跳错（9.9 → 36.0.19 / 48.0.7 / 49.0.4）。恶意 Wasm 可逃逸默认 Cranelift 引擎。
- **[Azure Kubernetes Configuration Service CVE-2026-83938](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-83938)**：关键功能缺认证，未授权网络提权，CVSS 10.0 Critical。微软云侧已完全缓解，客户无需操作（透明披露）。
- **[Microsoft Entra / AAD App Proxy CVE-2026-97785](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-97785)**：不当认证导致未授权网络提权，CVSS 10.0 Critical。同样由微软侧修复，客户无需操作。
- **[AWS Multi Model Server CVE-2026-115812 / 115813](https://aws.amazon.com/security/security-bulletins/2026-148-aws/)**：模型归档路径穿越可 RCE（9.8）、管理口可被导向任意下载目标；管理口默认无认证。≤1.1.11 全线受影响且项目已 EOL，无补丁，迁到受支持的推理服务；临时把管理口绑 loopback 并限制可达性。
- **[OpenWrt odhcpd CVE-2026-53921](https://github.com/openwrt/odhcpd/commit/0320032ae313452f3c8cb8725c621dd06c36dc03)**：DHCPv6 IA 响应堆溢出，可远程利用，CVSS 9.8。&lt; 25.12 受影响，升到 25.12+。
- **[Red Hat OpenShift Builds 1.9.2 / 1.8.3 Critical](https://access.redhat.com/errata/RHSA-2026:89131)**：含 CVE-2026-111943 等十余个 CVE，Critical。1.9.z 升到 1.9.2，1.8.z 见 [RHSA-2026:89081](https://access.redhat.com/errata/RHSA-2026:89081)。

- **[RHEL Grafana RHSA-2026:89732](https://access.redhat.com/errata/RHSA-2026:89732)**（Important）：Unified Alerting 信息泄露 CVE-2026-17183，以及 Go multipart DoS CVE-2026-94440。RHEL 10 升到 `grafana-10.2.6-28.el10_2.9`。
- **[RHEL jackson RHSA-2026:89734](https://access.redhat.com/errata/RHSA-2026:89734)**（Important）：jackson-core / databind 等，CVE-2026-68497 / 91777。
- **[Debian DSA-6582-1 brotli](https://security-tracker.debian.org/tracker/DSA-6582-1)**：CVE-2026-111497（与 10-22 Node.js 安全版本同一 Brotli 越界写），trixie 升到 `1.1.0-2+deb13u1`。
- **[Debian DSA-6584-1 varnish](https://security-tracker.debian.org/tracker/DSA-6584-1)**：CVE-2026-34475 / 93894，trixie 升到 `7.7.0-3+deb13u2`。
